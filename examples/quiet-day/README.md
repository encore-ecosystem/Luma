# Тихо — самостоятельная демка Luma

Небольшой планировщик дня на Encore: нативное окно и retained widgets Luma,
CSS с семантическими токенами, векторная иллюстрация и системный шрифт.

## Запуск

Из этой папки:

```sh
encore run
```

Нужны рабочие зависимости Luma и настроенный Encore index. Зависимость Luma
берётся из текущего репозитория (`path@../..`); остальные версии закреплены
в `encore.lock`.

## Что работает

- Сегодня / Все задачи / Выполнено, разделы и поиск по названию или категории.
- Отметка задач, добавление с проверкой названия, отмена и повтор изменений.
- Фокус-сессии на 15, 25 и 45 минут: запуск, пауза, продолжение, сброс.
  Время считается по монотонным часам; длительность заблокирована во время сессии.
- Tab / Shift+Tab, Space / Enter, Escape для закрытия формы; прокрутка к фокусу.
- При ширине менее 1000 px таймер переходит под задачи; менее 650 px
  боковая панель заменяется короткой навигацией. Минимальная ширина — 320 px.

Данные живут только в памяти и сбрасываются при закрытии. Поиск учитывает регистр.
Это демонстрация интерфейса, без сервера, аккаунтов и постоянного хранилища.

## Устройство

| Файл | Ответственность |
| --- | --- |
| `src/main.enq` | Окно, события, фокус и отрисовка |
| `src/model.enq` | Задачи, независимая история изменений, таймер, два теста |
| `src/view.enq` | Композиция стандартных виджетов Luma и SVG |
| `src/layout.enq` | Размеры секций для native flex с измерением текста |
| `app.css` | Цвета, типографика, отступы и состояния |

Приложение не использует Graphene. Новых C-файлов, растровых ассетов и
встроенных копий шрифтов нет. Вспомогательный расчёт размеров локален этому примеру;
исходники библиотеки Luma для демки не менялись.

### Обнаруженный дефект компилятора

В установленном Encore 0.1.6-neumann Unicode в description манифеста ломал
разрешение зависимостей. В двух минимальных проектах ASCII-вариант прошёл,
вариант с em dash завершился unresolved-import. В этом примере description
содержит ASCII. По workflow `encore-compiler-issues` опубликован
[Encore #164](https://github.com/encore-ecosystem/encore/issues/164).
Компилятор не менялся; обход не считается исправлением дефекта.
